# 부자가 되어보자...

## 페이지

- 시장 현황: index.html — 외국인 코스피·코스닥 현물, K200 선물 수급과 지수 교차차트.
- 신용잔고: credit.html — 고객예탁금·시장 전체 신용융자 잔고·동일 제공일의 신용융자/예탁금 비율.
- 차트: charts.html — 한국·미국·홍콩·일본 종목 검색, 일봉 가격과 시장 거래량, CSV.

## 주요 지표와 종목 차트

시장 현황의 수급 위에 미국 10년물 금리 / 코스피 / 코스닥 / 나스닥 / 다우 / S&P 500 / VIX / WTI / 브렌트 / 골드 / 실버 / 구리 순서로 12개 카드를 표시합니다. Yahoo Finance 일별 가격의 최근값과 같은 계열의 직전 제공일·1주/1개월/3개월 비교, 3개월 추이와 범위를 제공합니다. 금리 수준은 %이고 변화는 bp, 원유는 USD/배럴, 금·은은 USD/트로이온스, 구리는 USD/파운드입니다. 원자재는 근월물 연속 선물 시세이며 롤오버 영향이 있습니다.

scripts/collect-indicators.mjs가 기존 30분 Pages 예약 실행에서 data/indicators.json을 갱신합니다. 차트 범위의 첫 기준값인 Yahoo chartPreviousClose나 현재 quote 메타데이터를 전일 종가로 잘못 쓰지 않고, 일별 bar의 마지막 두 값을 비교합니다. 제공처 수집 실패는 마지막 정상 카드의 원래 날짜/시각과 함께 stale로 유지하며 0을 만들지 않습니다. 서버의 Yahoo 요청은 HTTP429로 제한돼 브라우저는 정기 수집 스냅샷을 읽습니다. 실시간 무지연 시세라고 표시하지 않습니다.

charts.html은 기존 종목 검색을 이용하며, 별도 stock-chart Edge Function이 입력 시장·코드·통화를 검증하고 네이버 검색 결과의 국가/코드가 정확히 일치하는 Reuters 식별자를 조회합니다. 국내·해외 /chart/{domestic|foreign}/item/{code}/day?startDateTime=...&endDateTime=...에서 실제 일봉 OHLCV를 수집합니다. Naver periodType=year 요약은 주봉이므로 일봉으로 쓰지 않습니다. HK 선행 0·통화 카운터·ADR·거래소를 구분하며 서로 다른 종목의 자료로 대체하지 않습니다.

캔들/종가 선, 1·3·6개월/1·2년, 날짜 슬라이더/마우스 조회, CSV(누락 값은 빈 셀)를 지원합니다. 거래량은 공개 시장 주식/ETF 좌수이고 사용자 계좌 수량과 무관합니다. 누락 OHLC/거래량은 생성하지 않습니다. 종목 변경 실패 시 이전 종목 차트를 비우며 같은 종목의 갱신 실패 시 기존 종목/기간을 유지합니다. 로그인 없이 조회, 5분 캐시와 같은 요청 병합, 게이트웨이 JWT 검증을 유지합니다. 새 개인 데이터/DB 테이블은 없습니다.

## 외국인 수급

Supabase market-flow Edge Function이 네이버페이 증권의 공개 투자자별 매매동향과 지수 분봉을 조회합니다. 브라우저는 표시 중 60초마다 갱신하고, 함수는 55초 캐시를 사용합니다. 실패하면 data/market.json의 마지막 저장 자료와 시각을 표시합니다.

현물 순매수 금액은 원 단위를 억원으로 환산하고, 선물은 제공처의 매수금액−매도금액(백만원 단위)을 억원으로 환산합니다. 계약 수에 현재가를 곱해 추정하지 않습니다. KOSPI/KOSDAQ/FUT를 구분하며 수급과 지수가 겹치는 같은 거래일의 정규장 구간만 표시합니다. 두 세로축은 개별 범위이며, 시간 슬라이더와 차트 클릭으로 시점을 확인합니다. 제공처 자료는 잠정치일 수 있습니다.

콜·풋 수급·미결제약정은 아직 연결하지 않았습니다. 확인되지 않은 옵션 수치를 표시하지 않습니다.

## 신용잔고

신용잔고 메뉴는 현재 탭에서 별도 페이지로 이동하며 로그인 없이 조회합니다. 고객예탁금·신용융자 잔고·예탁금 대비 비율을 세 차트로 표시하고 3개월·6개월·1년·3년 범위와 동기화된 날짜 선택을 제공합니다. 기본은 최근 제공일 기준 1년입니다.

scripts/collect-credit.mjs는 네이버페이 증권 증시자금동향의 공개 API trendDeposit을 pageSize=200, startIdx=0~3(페이지 번호)으로 읽고 최근 3년의 일별 자료를 data/credit.json에 저장합니다. 차트 API는 긴 기간 요청에도 약 60일만 반환하므로 사용하지 않습니다. 원본 customerDeposit/creditLoan 단위는 억원이며, 화면은 10,000으로 나눠 조원 표시, 비율은 같은 행의 신용융자÷예탁금×100입니다. 증감은 직전 제공일 대비이며 비율 변화는 %p로 구분합니다. 빠진 값을 0으로 채우지 않습니다.

기존 30분 예약 Pages workflow에 수집을 추가했습니다. 일별 발표 통계이며 실제 거래일보다 제공처의 게시가 늦을 수 있어 자료 기준일과 수집 시각을 따로 표시합니다. 수집 실패 시 마지막 정상 자료와 그 기준일·수집 시각을 보존하고 경고합니다. 열린 페이지는 5분마다 배포된 자료를 재확인합니다. 금융투자협회 원자료 확인 링크도 제공합니다. 계좌 DB나 사용자 거래를 조회하지 않습니다.

## 공유 일지와 계좌 연결

공개 사이트에서 GitHub 로그인 → 의견 나누기 → 공개 닉네임 입력 → 자동 공유 연결하기 → 계좌 일지에서 연결 완료하기.

계좌 앱이 URL fragment의 연결 코드를 읽고 주소에서 제거한 뒤 공유할 공개 닉네임을 표시합니다. 본인의 계정인지 확인하고 ‘새 기록 자동 공유 연결’을 누르면 연결됩니다. 코드가 전달되지 않으면 공개 화면의 코드를 복사해 계좌 앱의 ‘공개 투자노트와 연결’에 입력할 수 있습니다. 코드는 비밀번호처럼 취급하고 채팅이나 저장소에 올리지 않습니다.

공개 데이터는 종목·매수/매도·단가와 통화·거래일·매매 이유·복기입니다. 계좌 앱의 서버에서 명시한 필드만 전송하며 수량·총체결금액·계좌번호·잔고·KIS 키는 전송하지 않습니다. 공개 테이블에도 수량·총액·계좌정보 컬럼은 없습니다. 기존에 공유 대상인 거래의 단가는 다음 계좌 동기화에서 보완합니다. 기존 비공개 거래는 계속 공개하지 않습니다.

직접 공유 폼은 종목명이나 티커로 한국·미국·홍콩·일본을 검색합니다. 네이버페이 증권 자동완성 결과에 국가·거래소·코드를 표시하고, 선택하면 시장·코드·가격 통화를 채웁니다. 홍콩 코드의 앞자리 0과 일본 영숫자 코드를 보존하며 ADR/본주를 구분합니다. 검색 지연 시 직접 입력도 가능합니다. 검색 결과로 현재 주가를 단가에 채우지 않으며 실제 매수/매도 단가를 입력합니다.

매수/매도 구분에 맞는 가격과 KRW/USD/HKD/JPY(홍콩의 명시된 CNY·USD 카운터 포함)를 저장합니다. 단가가 없던 기존 글에는 가격 미입력으로 표시합니다. 시장·통화 조합과 양수 가격을 DB에서도 검증합니다. 홍콩·일본은 직접 공유 및 종목 검색 지원이며 기존 KIS 자동 가져오기는 한국·미국 범위를 유지합니다.

자동 공유는 연결 이후 새 체결부터 적용합니다. 기존 거래는 연결 시 기준 목록으로만 등록하며 공개하지 않습니다. 같은 날 체결 시각을 확인할 수 없는 과거 거래도 제외합니다. 공유 대상 거래의 복기를 수정하면 공개 글에 반영합니다. 계좌 앱이 열린 동안 기존의 5분 동기화 주기를 사용하며 앱이 닫혀 있으면 KIS 자동 조회도 멈춥니다.

공개 사이트의 journal_share_links에는 연결 코드의 SHA-256 해시만 저장하고 RLS로 본인만 접근합니다. 계좌 앱은 코드를 서버에서 AES-GCM으로 암호화해 보관합니다. journal-sync Edge Function은 이 연결 코드를 검증하며 사용자나 소유자 ID를 외부 입력으로 신뢰하지 않습니다.

journal_posts는 공개 읽기, 작성자 수정·삭제만 허용합니다. 계좌 연동 표시와 외부 식별자는 클라이언트가 위조할 수 없도록 컬럼 권한을 제한합니다. 계좌 연동 글을 삭제하면 재수집으로 복원되지 않도록 내부 제외 목록을 유지합니다. journal_post_comments는 글별 공개 댓글이며 로그인한 작성자만 추가·삭제할 수 있습니다. 댓글은 분당 5개, 본문 2,000자로 제한합니다.

자동 공유 중지 후 기존 공개 글은 개별 삭제할 수 있습니다. 두 서비스는 한 번 연결한 이후에만 새 기록을 전송합니다.

## 리포트 수집

scripts/collect-research.mjs가 최근 7일 범위에서 네이버 국내 보고서 최대 200건, 연합인포맥스 해외 보고서 최대 200건을 수집합니다. 국내 목표가는 제공처가 명시한 같은 증권사의 이전 목표가와 비교합니다. 비교 불가 값은 채우지 않습니다. 실적은 증권사 리뷰이며 도입부에서 확인된 실제 영업이익과 YoY만 표시합니다. 전망·누적·자회사 수치는 제외합니다.

GitHub Actions는 매시 UTC 17분·47분에 리포트·시장 fallback 자료 수집과 Pages 배포를 실행합니다. 시장 화면의 장중 갱신은 이 예약 배포와 별개로 Edge Function을 사용합니다. GitHub 예약 실행은 지연되거나 비활동 정책에 따라 중지될 수 있습니다. 원문 전체나 PDF를 재게시하지 않고 짧은 제목·사실 정보·원문 링크만 저장합니다.

## 개발·검증

Node 22 이상에서 npm ci, npm test, npm run build, npm run preview를 사용합니다. 미리보기는 http://127.0.0.1:5183/preview/ 입니다.

- npm test: 기존 비공개 권한, 공유 글·댓글 권한, 연결 코드 보호, 민감 컬럼 부재, 삭제 제외 처리, 리포트 수치와 수급 단위·시간 구간 테스트.
- node tests/pages-browser.mjs: 별도 페이지/현재 탭 이동, 실제 수급 차트, 모바일, 공유 일지·댓글 CRUD, XSS·공개 payload 검증.
- node tests/research-browser.mjs: 리포트 검색·분류·모바일·오류 보존.
- node tests/stock-search-browser.mjs: 실제 4개국 검색·코드/통화 자동 입력·매수/매도 단가 저장/수정·모바일·검색 실패 대체 입력.
- node tests/credit-browser.mjs: 실제 일별 자료·세 차트·금액/비율·기간/날짜·모바일 축 가독성·현재 탭 이동·오류와 이전 자료 보존.
- node tests/charts-browser.mjs: 실제 12개 지표 순서·단위·수급 위 배치, 4개국 실차트/거래량, 기간/날짜/캔들/선/CSV, 모바일, 다른 종목 자료 혼동 방지.
- PLAYWRIGHT_MODULE과 CHROME_PATH로 브라우저 설치 경로를 지정합니다.
- TEST_SITE_URL을 지정하면 공개 주소에서도 읽기/모의 API 검증을 실행할 수 있습니다.

Supabase migrations는 적용된 초기 파일을 다시 실행하지 않습니다. 새 스키마 변경만 새 migration으로 추가합니다. 서비스 키·KIS 키는 정적 파일에 넣지 않습니다. market-flow는 공개 anon JWT로 호출하고 journal-sync는 서버 간 연결 코드를 직접 검증합니다.

OAuth 설정값은 SETUP.md에 있습니다. 기본 callback은 프로젝트 Supabase 주소, 돌아오는 주소는 GitHub Pages 기본 경로를 사용하고 로그인 후 원래의 공개 페이지로 복귀합니다.

## 확인 범위

실제 GitHub 로그인·수동 저장·새로고침 유지는 사용자 확인을 완료했습니다. 새 자동 공유는 테스트용 연결 코드로 실제 Edge Function의 허용·거부와 저장 컬럼을 검증했고, 계좌 앱의 공개 payload와 신규 거래 기준도 테스트했습니다. 실제 계좌 앱과 GitHub 회원의 연결은 사용자가 위 절차로 한 번 완료해야 합니다.
